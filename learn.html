RESPONSIBLE AI & PRIVACY

Never paste participant data into public AI tools.

Raw survey CSVs, interview transcripts, and GPS coordinates must remain inside secure organizational storage. When using LLMs for coding help or qualitative analysis, use anonymized dummy schemas or run open-weights models locally (such as via Ollama) with zero external data sharing.
